# AI コーチング・エージェント（毎朝 Slack 通知）

浅尾洋伸さん（For A-career 社長）専属の 3 人の AI コーチが、毎朝 1 回 Slack に
コーチングを届ける仕組みの設定メモです。ここを読めば、内容・時刻・送信先の
変更方法が分かります。

## 概要

| 項目 | 設定 |
|---|---|
| コーチ | ① 英語コーチ 🇬🇧　② ダイエットコーチ 🥗　③ 経営コーチ 📊 |
| 頻度 | 毎日 1 回 |
| 時刻 | 06:57 JST（cron `57 21 * * *` = 21:57 UTC） |
| 送信先 | Slack（初期設定は本人 DM: `U06NUEZ2J4X`） |
| 形式 | 3 人それぞれ別メッセージ（合計 3 通） |
| 判断材料 | 本人の日次報告ベース（同じ Slack スレッドの直近履歴を毎朝読んで評価） |
| 記録先 | Notion DB「コーチング記録（英語・ダイエット・経営）」に毎朝 自動記録 |
| 実行エンジン | Claude Code の Routine（毎朝 このコーチング用セッションを起こして実行） |
| Routine ID | `trig_01XeukXwB6We24tufdJx5pVd` |
| Notion DB | data source `collection://d4f67b16-e5be-49ce-afc5-a09a0e7d3d48` |

## 仕組み

1. 毎朝 06:57 JST に Routine がコーチング用の Claude セッションを起こす。
2. セッションは送信先チャンネルの直近履歴（本人の報告＋前日までのコーチ投稿）を読む。
3. **昨日の本人の報告を Notion DB に 1 行として記録する**
   （英語／食事／運動／経営数字、実施チェック、コーチ所感）。
4. 3 人のコーチとして、それぞれ別メッセージで Slack に投稿する。
   - 英語コーチ：昨日の学習を確認 → 称賛/後押し → 今日のメニュー提案 → 報告依頼
   - ダイエットコーチ：昨日の食事・運動を確認 → 称賛/リカバリー → 今日の目標 → 振り返り依頼
   - 経営コーチ：直近の数字に言及 → 今日のアクション提案 → 中長期の問いかけ
4. 本人がそのチャンネルに「今日は英語 20 分やった」「昼は控えめ／夜ジム」「今日の受注◯件」
   などと一言返しておくと、翌朝のコーチがそれを踏まえて振り返り＋助言する。

**ポイント：コーチは "本人の報告" を材料に監視・助言します。報告が無い項目は
翌朝「未報告」として優しく確認されます。毎日ひとことでも返すほど精度が上がります。**

## 使い方（本人向け）

- 毎朝、3 通のコーチメッセージが届く。
- 各メッセージの問いかけに、そのチャンネルで気軽に返信する（箇条書き・一言で OK）。
  - 例：`英語: Podスクリプト15分＋シャドーイング` / `食事: 昼サラダ、夜◯◯ / 運動: 8000歩`
  - 例：`経営: 本日受注3件、売上見込◯◯万、粗利率◯%`
- 返信内容は翌朝のコーチングに反映される。

## 変更方法

### 送信先を「専用チャンネル」に切り替える

Slack 連携ではチャンネルの新規作成 API が使えないため、チャンネル自体は
Slack 上で手動作成する必要があります。

1. Slack で新規チャンネル（例：`#ai-coaching`、非公開でも可）を作成する。
2. そのチャンネルを開く。
3. 担当（Claude）に「チャンネル `#ai-coaching` に切り替えて」と伝える。
   - Claude が既存 Routine を作り直し、送信先 channel_id を新チャンネルに変更する。

### 時刻を変える

Routine の cron を更新する（例：夜 21:00 JST にしたい → `0 12 * * *`）。
JST から UTC へは 9 時間引く。担当に「毎朝◯時に変えて」と伝えれば更新します。

### コーチの人格・内容・トーンを変える

Routine のプロンプト（本ファイル上部で説明した各コーチの指示）を編集する。
「英語コーチをもっと厳しめに」「経営コーチに毎週月曜だけ週次レビューを」等、
自然文で担当に伝えれば反映します。

### 一時停止 / 削除

- 一時停止：Routine を disabled にする。
- 完全削除：Routine（`trig_01XeukXwB6We24tufdJx5pVd`）を削除する。

## 注意事項・制約

- **実行方式の経緯**：当初は「毎朝まっさらな新セッションを起動して投稿」する方式で
  組んだが、新セッションからは Slack / Notion 連携が使えず投稿・記録に失敗した。
  そのため、Slack / Notion 連携が実証済みの「このコーチング用セッションを毎朝起こす」
  自己起動方式（self-bind）に切り替えた。この方式は連携がそのまま使えるため確実。
- ただしこの方式はセッションが長期間 reclaim（回収）されないことに依存する。毎朝の
  起動でセッションを温め続けるが、万一 朝に投稿が来ない場合は担当に一声かけてほしい
  （その場で再実行・再設定できる）。
- cron はサーバー時刻（UTC）基準です。`57 21 * * *`（UTC）= 06:57 JST。
- **Slack の「自分あて DM」には通知（プッシュ/バッジ）が出ない仕様**です。確実に
  通知を受けたい場合は、専用チャンネルを作成して Claude アプリを招待し、そこへ
  送信先を切り替えてください（手順は上記「送信先を専用チャンネルに切り替える」）。

## Notion への自動記録

- 記録先 DB：「コーチング記録（英語・ダイエット・経営）」
  （data source `collection://d4f67b16-e5be-49ce-afc5-a09a0e7d3d48`）。
- 毎朝の Routine が、前日に本人が Slack に書いた報告を読み取り、その日の 1 行として
  Notion に記録する（英語／食事／運動／経営数字、実施チェック、コーチ所感）。
- Slack はあくまで「やりとりの場」、Notion は「蓄積・振り返りの場」という役割分担。
  Slack に一言返信しておくほど、翌朝の記録とコーチングが充実する。
