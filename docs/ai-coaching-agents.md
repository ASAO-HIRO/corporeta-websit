# AI コーチング・エージェント（毎朝 Slack 通知）

浅尾洋伸さん（For A-career 社長）専属の 3 人の AI コーチが、毎朝 1 回 Slack に
コーチングを届ける仕組みの設定メモです。ここを読めば、内容・時刻・送信先の
変更方法が分かります。

## 概要

| 項目 | 設定 |
|---|---|
| コーチ | ① 英語コーチ 🇬🇧　② ダイエットコーチ 🥗　③ 経営コーチ 📊 |
| 頻度 | 毎日 1 回 |
| 時刻 | 06:57 JST（cron `57 21 * * *` = 21:57 UTC） |
| 送信先 | Slack（初期設定は本人 DM: `U06NUEZ2J4X`） |
| 形式 | 3 人それぞれ別メッセージ（合計 3 通） |
| 判断材料 | 本人の日次報告ベース（同じ Slack スレッドの直近履歴を毎朝読んで評価） |
| 実行エンジン | Claude Code の Routine（毎朝 新セッションを起動して実行） |
| Routine ID | `trig_013NkF5LmNrd85dtQjU5jcYo` |

## 仕組み

1. 毎朝 06:57 JST に Routine が新しい Claude セッションを起動する。
2. セッションは送信先チャンネルの直近履歴（本人の報告＋前日までのコーチ投稿）を読む。
3. 3 人のコーチとして、それぞれ別メッセージで Slack に投稿する。
   - 英語コーチ：昨日の学習を確認 → 称賛/後押し → 今日のメニュー提案 → 報告依頼
   - ダイエットコーチ：昨日の食事・運動を確認 → 称賛/リカバリー → 今日の目標 → 振り返り依頼
   - 経営コーチ：直近の数字に言及 → 今日のアクション提案 → 中長期の問いかけ
4. 本人がそのチャンネルに「今日は英語 20 分やった」「昼は控えめ／夜ジム」「今日の受注◯件」
   などと一言返しておくと、翌朝のコーチがそれを踏まえて振り返り＋助言する。

**ポイント：コーチは "本人の報告" を材料に監視・助言します。報告が無い項目は
翌朝「未報告」として優しく確認されます。毎日ひとことでも返すほど精度が上がります。**

## 使い方（本人向け）

- 毎朝、3 通のコーチメッセージが届く。
- 各メッセージの問いかけに、そのチャンネルで気軽に返信する（箇条書き・一言で OK）。
  - 例：`英語: Podスクリプト15分＋シャドーイング` / `食事: 昼サラダ、夜◯◯ / 運動: 8000歩`
  - 例：`経営: 本日受注3件、売上見込◯◯万、粗利率◯%`
- 返信内容は翌朝のコーチングに反映される。

## 変更方法

### 送信先を「専用チャンネル」に切り替える

Slack 連携ではチャンネルの新規作成 API が使えないため、チャンネル自体は
Slack 上で手動作成する必要があります。

1. Slack で新規チャンネル（例：`#ai-coaching`、非公開でも可）を作成する。
2. そのチャンネルを開く。
3. 担当（Claude）に「チャンネル `#ai-coaching` に切り替えて」と伝える。
   - Claude が既存 Routine を作り直し、送信先 channel_id を新チャンネルに変更する。

### 時刻を変える

Routine の cron を更新する（例：夜 21:00 JST にしたい → `0 12 * * *`）。
JST から UTC へは 9 時間引く。担当に「毎朝◯時に変えて」と伝えれば更新します。

### コーチの人格・内容・トーンを変える

Routine のプロンプト（本ファイル上部で説明した各コーチの指示）を編集する。
「英語コーチをもっと厳しめに」「経営コーチに毎週月曜だけ週次レビューを」等、
自然文で担当に伝えれば反映します。

### 一時停止 / 削除

- 一時停止：Routine を disabled にする。
- 完全削除：Routine（`trig_013NkF5LmNrd85dtQjU5jcYo`）を削除する。

## 注意事項・制約

- Routine は毎朝「新しいセッション」を起動して実行するため、Slack 連携が
  そのセッションで有効である必要があります。初回はテスト実行で疎通確認済み。
- 万一、朝の時刻に投稿が届かない場合は連携の再認証が必要な可能性があるため、
  担当に連絡してください。
- cron はサーバー時刻（UTC）基準です。実際の到着時刻がズレる場合は cron を調整します。
