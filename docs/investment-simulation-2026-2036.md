# 3. 3C分析(投資先としての自社グループ vs 市場運用)

## Customer(顧客・市場)
- 中核顧客は**物流・製造・介護の中小企業**。労働人口減少で「いい人が採れない」→「人がいないと会社が続かない」へ課題が格上げされる10年(方向性メモ予測2)。採用の外部化(RPO)は経営課題化し、解約されにくい。
- 同じ顧客層が**後継者不在**という第二の課題を持つ(不在率50.1%)。採用支援の顧客基盤がそのままM&Aソーシングのリストになる — **リクロジ×FAC capitalの顧客シナジーは実在する**。
- 一方、金融市場(株・債券・不動産)の「顧客」は自分自身であり、リターンの源泉は市場全体の成長のみ。顧客関係による超過収益は存在しない。

## Competitor(競合)
- 人材紹介: リクルート/パーソル等の大手+AIエージェント新興。**求人票マッチング型は中抜きされる**。リクロジの「常駐型RPO・継続率・業界特化」は大手が採算的に降りてこないニッチ。
- スモールM&A: 大手PEはEBITDA数億円以上に集中。**営業利益3,000万〜1億×3-5倍のゾーンは事業会社系買い手が希少**で、ブルパス・キャピタルとの協業経験(PJ Care)・仲介ネットワーク(ミナックル、M&Aクラウド等)は既に稼働中。
- 市場運用: 競合=世界中のプロ投資家。**個人がエッジを持てる余地はゼロ**(だからこそインデックスが合理的、だが超過リターンもない)。

## Company(自社)
- 強み: 粗利率89.7%のHRモデル、物流RPO継続率60.9%、700人組織と若手採用力、**売り買い両サイドのM&A実績**(CyXenエグジット完了、買収検討多数)、意思決定速度。
- 弱み: 労働分配率71.7%、利益未達(Q1達成率69.4%)、赤字子会社への「見えない輸血」体質(QUEST)、投資運用の社内専門性は無い。
- **投資判断への翻訳: 自社周辺に投じる1円は「エッジ付きの1円」、市場に投じる1円は「エッジなしの1円」。ただし自社集中は下振れも一点に集中する。**

# 5. 10パターン×10年シミュレーション

## 共通前提
- 投下資本: 10億円(個人5.6億+法人4億強)。2026年8月〜2027年に段階投入
- 期間: 2026年8月→2036年7月(10年)
- シナリオ: 悲観(確率25%)/中立(50%)/楽観(25%)
- 数値は**税引前の資産評価額**(売却時に個人譲渡20.315%、法人約30%の課税が別途かかる。パターン間の比較には影響小)
- 為替・インフレは各シナリオのリターンに内包

## P1: 全世界株インデックス一括(オルカン/S&P500)
- **内容**: 個人・資産管理会社でVT/オルカン等を一括買付、放置。新NISA枠(1,800万)は即埋め
- **前提CAGR**: 悲観2%(円高転換・株価調整)/中立6.5%/楽観10%
- **結果**: 12.2 / 18.8 / 25.9億(期待値18.9億)
- **評価**: 再現性最強・手間ゼロ。ただし日経PER22倍・S&P高値・円安162円という「三重の高値圏」からの一括は10年リターンを圧縮しやすい。**やるなら24〜36か月の時間分散が必須**
- **浅尾適性**: エッジ不要=誰がやっても同じ。「退屈に耐えられるか」が唯一の関門

## P2: インデックス+PBレバレッジ1.5x(Julius Baer等)
- **内容**: P1に加えロンバードローンで0.5x上乗せ(方向性メモの財布4上限1.5xと整合)。借入コスト2.5%想定
- **結果**: 11.9 / 21.8 / 32.5億(期待値22.0億)
- **評価**: 中立以上ではP1を明確に上回る。悲観時は追証リスクで実際は11.9億より悪化しうる(強制売却が最悪のタイミングで起きる)。金利上昇局面では借入コストがじわじわ効く
- **浅尾適性**: 財布4の設計通り「信用枠」として使うのが正解。攻めのレバは非推奨

## P3: 日本株高配当・バリュー集中
- **結果**: 11.6 / 17.1 / 22.6億(期待値17.1億)
- **評価**: 配当インカムは心理的に続けやすいが、日経68,000円・PER22倍からのエントリーは向こう10年の期待値を削る。P1に対する優位性なし

## P4: 債券・ディフェンシブ(10年国債2.8%・社債ラダー・現金)
- **結果**: 12.2 / 13.2 / 14.1億(期待値13.2億)
- **評価**: 30年ぶりの金利水準で「守りにも利回りが付く」時代にはなった。ただし10年で1.3倍では「1番お金持ち」には絶対に届かない。**役割は待機資金の置き場**(M&A弾薬を国債・MMFで待たせる)であり、主戦場ではない

## P5: 都心収益不動産(レバ2x・一棟レジ)
- **内容**: 自己資金10億+借入10億で20億の都心レジ取得。NOI4%、借入2.5%(悲観3.5%)、価格成長+1%(悲観▲1.5%/楽観+3%)
- **結果**: 11.2 / 18.0 / 24.0億(期待値17.8億)
- **評価**: 71か月連続上昇・バブル超えの価格水準で、金利1.5〜2%へ向かう世界。**イールドギャップ(4%-2.5%)が歴史的に薄く、「金利上昇×価格調整」の悲観シナリオで自己資本が半減しうる**。10年前なら正解だった投資。今は期待値でインデックスに勝てない
- **浅尾適性**: 不動産運用の社内専門性なし。フルコミットは非推奨

## P6: 築古木造(4年償却)×3億+インデックス7億
- **内容**: 財布3の設計通り。個人の高税率所得(役員報酬・退職金)に対し、築22年超木造の建物部分を4年償却でぶつけ、5年超保有後に長期譲渡(20.315%)で売却。税率差(最大55%→20%)のアービトラージ。残り7億はP1
- **結果**: 13.0 / 19.5 / 26.7億(期待値19.7億)
- **評価**: **悲観シナリオが全パターン中最強(13.0億)**。節税効果は市場と無相関で、下値を固くする。ただし規模の上限(良質な築古木造は3億も積めれば十分)があり、これ単独では主役になれない
- **浅尾適性**: 筧先生と設計済み。役員退職金・HD化(12月)とセットで年内に器を作るのが最効率

## P7: FAC capital — 承継型LBO連続買収(buy-and-build)
- **内容**: 10億を4年で8件に分散(1件あたりエクイティ1.25億+LBO2.5億=EV3.75億、EBITDA約0.94億を4倍で取得)。リクロジRPOで採用再生・若手CXO派遣でPMI。7年平均保有
- **シナリオ**: 悲観=成功1件/現状維持3件/失敗4件・出口4倍。中立=成功2/維持4/失敗2・出口5倍。楽観=成功4/維持3/失敗1・出口6.5倍
- **結果**: 12.9 / 27.3 / 59.0億(期待値31.6億)
- **評価**: **市場運用系(P1-P6)を期待値で圧倒する。** 源泉は(a)EBITDA3-5倍という構造的に安い仕入れ値、(b)LBOレバレッジ、(c)リクロジ採用シナジーという他の買い手が持たない改善装置、(d)10年続く売り案件増加。M&A成功確率は一般に20-30%だが、悲観シナリオはそれを織り込んでもエクイティを守れる(失敗時回収20%前提)
- **注意**: 「エモく買う・高値掴みしない」規律が生命線。1件目からフルサイズで行かない。仲介経由の相場感(営業利益5,000万×3-5倍で既に打診中)を1〜2年蓄積してから買収本格化するのが5ヵ年計画とも整合
- **浅尾適性**: ◎。多事業への好奇心の正しい出口(防火壁の設計通り)

## P8: 本業再投資 — リクロジ増員×AI人材マッチング立ち上げ
- **内容**: 10億をFACG本体に投入。リクロジ+15名採用の前倒し・地方拠点・AI人材マッチング(竹シナリオ営利1.86億)・えーかおAI化。創出される増分営業利益を事業価値換算
- **シナリオ**:
  - 悲観: 労働分配率が下がらず増分営利+1億止まり×5倍 = **5.0億(投資が半減)**
  - 中立: 増分営利+4.5億×8倍 = **36.0億**(5ヵ年計画のリクロジFY31営利15億が概ね実現する世界)
  - 楽観: リクロジFY12構想(売上100億・営利10億超)が実現しエグジット/上場、増分営利+10億×10-12倍 = **110.0億**
- **結果**: 5.0 / 36.0 / 110.0億(**期待値46.8億で全パターン1位**)
- **評価**: 期待値最大の源泉は「粗利率89.7%の事業で、顧客需要(人手不足)が10年構造的に続く」こと。**ただし悲観が最も深い。** Q1の利益達成率69.4%が示す通り、「人を採れば利益が増える」はまだ証明されていない。労働分配率71.7%→50%の転換なしに資本を入れるのは、QUESTの輸血をグループ規模で再演するリスク
- **投資の条件(これがないならP8の金は入れない)**: ①ステージゲート決議(8月)、②労働分配率の月次公開、③「3年で営業利益率15%以上」基準の機械的適用
- **浅尾適性**: ◎。ただし「意志ではなく制度」が先

## P9: AI・ベンチャー集中(ソフィエイト型買収+エンジェル)
- **内容**: AI受託(ソフィエイト等)の買収、AIスタートアップへのエンジェル/LP出資に10億集中
- **結果**: 3.0 / 14.0 / 55.0億(期待値21.5億)
- **評価**: 上振れは大きいがべき乗分布で、飛地M&Aの成功確率は10-20%。ソフィエイト単体は「営業力補完」のシナジーが実在するため**小さく(1〜2億)買う分にはP7の1件として合理的**。10億をこの領域に張るのは投機
- **浅尾適性**: △。本人も「維持・最適化が苦手」なタイプ×同じタイプの創業者、はPMIが乗りにくい

## P10: 自宅購入(3億・ローン活用)+インデックス7億
- **内容**: 検討中の自宅は住宅ローン(みずほ相談中)で買い、手元資本は極力投資へ。3億自宅+7億P1
- **結果**: 11.5 / 16.6 / 22.2億(期待値16.7億)
- **評価**: 自宅は資産だがキャッシュを生まない。**「自宅はローンで買って売却益は事業に回す」が正解**で、これは既に取っている行動(住宅ローン相談)と一致。QOL投資として別枠で考え、シミュレーション上は主役にしない

## P11: 推奨ミックス — 4つの財布への規律ある配分
- **配分**: 本業再投資4億(40%) + FAC capital 3億(30%) + インデックス2億(20%、時間分散) + 築古木造1億(10%)
- **結果**: 9.7 / 28.5 / 69.9億(**期待値34.2億で実質2位**)
- **評価**: P8の上振れを取りながら、悲観でも9.7億(P8単独の5.0億に対し約2倍)を確保。**「エッジのある所に集中しつつ、エッジの外(市場)に2〜3割逃がして自社集中リスクをヘッジする」** 構造。方向性メモv2の財布1〜4の優先順位そのもの
- **10年後の総資産イメージ(中立)**: 投資部分28.5億 + 既存事業価値の増分(労働分配率改善が進めばグループ営利10億×8倍=80億規模の企業価値、浅尾持分次第) — **「投資」と「本業の利益体質転換」の両輪が揃って初めて、10年後の桁が変わる**

# 6. 解釈 — なぜこの順位になるのか

1. **エッジの有無がすべて。** P1〜P6(市場運用)の期待値は13〜22億のレンジに収束する。市場が効率的である以上、ここに差はつかない。P7/P8だけが期待値30〜47億に跳ねるのは、「安く仕入れる構造(EBITDA3-5倍)」「顧客基盤シナジー」「10年続く構造的需要」という**市場外のエッジ**があるから。
2. **ただしエッジは実行力に依存する。** P8の悲観5.0億は、Q1利益未達・労働分配率71.7%という現実の延長線。エッジは「あるだけ」では現金化されない。撤退規律・ステージゲート・輸血透明化(8月決議予定)が先行条件。
3. **今は「市場に張る」タイミングとして最悪に近い。** 日経PER22倍・S&P高値・都心不動産バブル超え・円安162円・金利上昇局面 — 伝統資産はすべて高値圏。逆に**売り案件が構造的に増える事業承継市場だけが「買い手優位」**。マクロ環境が、自社エッジと同じ方向を指している。
4. **守りは債券ではなく「規律」で買う。** 悲観シナリオの深さを決めるのは資産クラスではなく、撤退ラインの有無(QUESTとboomの対比が社内に実証データとしてある)。
5. **流動性は義務。** P7/P8は10年ロックの非流動資産。P11で市場性資産2〜3割を残すのは、リーマン級(あるいは2027年利上げショック)が来た時に**「安く買える側」に立つため**の弾薬でもある。
