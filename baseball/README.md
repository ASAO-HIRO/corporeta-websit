# ⚾ パワフル野球 かんたん版

パワプロ風の操作感をブラウザだけで再現した、簡易野球ゲームです。
外部ライブラリ・画像・音声ファイルは一切使っていません（HTML + CSS + JavaScript のみ）。

## 遊びかた

`baseball/index.html` をブラウザで開くだけで動きます。

```bash
# ローカルサーバで開く場合（任意）
cd baseball
python3 -m http.server 8000
# → http://localhost:8000/
```

## 操作方法

### タイトル画面
| キー | 動作 |
| --- | --- |
| ↑ ↓ | 項目の選択 |
| ← → | 設定の変更（チーム / 先攻後攻 / イニング / モード） |
| スペース・Enter | 決定 |

- **チーム**: 6球団から選択。対戦相手はランダム
- **イニング**: 1 / 3 / 6 / 9 回制
- **モード**: `攻守` = 投げて打つ / `打撃のみ` = 守備はおまかせ

### 打撃
| キー | 動作 |
| --- | --- |
| ← ↑ → ↓ | ミートカーソル移動 |
| スペース | スイング |
| Z | 強振 ⇔ ミート打ち 切替 |
| X | バント（構える／解除） |

ボールが**ホームベースに到達した瞬間**にスイングするとジャストミート。
カーソルとボールの重なり（＝ミート）とタイミングの両方が良いほど、強い打球になります。

- **強振**: カーソルは小さいがパワーが乗る
- **ミート打ち**: カーソルが大きく当てやすいが飛距離は落ちる
- 芯を外すとファウルや凡打に。タイミングが早いと引っ張り、遅いと流し打ちになります

### 投球（攻守モードの守備時）
| キー | 動作 |
| --- | --- |
| 1〜6 | 球種選択（投手ごとに持ち球が違います） |
| ← ↑ → ↓ | コース指定 |
| スペース | 投球 |

カーソルは「ボールが最終的に到達する位置」を指します。コントロールが低い投手ほど狙いからブレます。

### 共通
| キー | 動作 |
| --- | --- |
| スペース・Enter | メッセージ送り |
| M | 効果音 ON / OFF |
| R | タイトルへ戻る |

## 実装している要素

- **選手能力**: ミート / パワー / 走力 / 弾道（打者）、球速 / コントロール / スタミナ / 持ち球（投手）。S〜G のランク表示
- **球種**: ストレート、スライダー、カーブ、フォーク、シュート、チェンジアップ、シンカー（終盤に変化）
- **打球シミュレーション**: 打球初速・打球角度・打球方向から飛距離と滞空時間を計算し、9人の野手の守備範囲で結果を判定
  - ホームラン／三塁打／二塁打／単打／内野安打／ポテンヒット／ゴロアウト／フライアウト／ライナーアウト／ゲッツー／犠牲フライ／ファウル／エラー
- **試合進行**: カウント（B/S/O）、四球、三振、走者の進塁と得点、イニング交代、投手交代（スタミナ切れ）、サヨナラ、延長（最大 +3 回）、引き分け
- **表示**: ラインスコア（R/H/E）、打者・投手カード、打席結果ログ、試合終了後の打撃成績

## バランス調整の目安

CPU 同士で 30 試合を自動対戦させたときの平均値（9 回制）:

| 項目 | 数値 |
| --- | --- |
| 1チームあたり得点 | 約 4.3 |
| 1チームあたり安打 | 約 9.5 |
| 打率 | 約 .263 |
| 三振 | 約 12 |
| 本塁打 | 約 1.7 |
| 投球数 | 約 260 |
